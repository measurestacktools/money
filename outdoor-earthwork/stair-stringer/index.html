Stair Calculator

Steps = ceil(totalRise ÷ maxRiser). Actual riser = totalRise ÷ steps. Run = steps × tread depth.

Enter your measurements and press Calculate.

Actual product yields vary — check the manufacturer's specs. Estimated cost (if shown) uses YOUR price, not a market price.

Formula

Comfort rule: riser 7–7.5 in, tread 10–11 in; check code for max riser/min tread.

Worked example

Example: 36-in rise ÷ 7.5 = 4.8 → 5 steps × 7.2-in risers; run 5 × 11 = 55 in.

Questions

What is code for stairs?

Commonly max ~7.75-in riser, min ~10-in tread — verify local code; this is planning math.
